## Never confuse these levels

```text
North Star
└── Program
    └── Work Package
        └── Task
            └── Current operation
```

The current operation may be narrow. It never becomes the North Star.

## Cross-cutting separation

```text
Verifier produces an assessment.
Authority policy permits or denies a transition.
Transition logic records the state change.
Repository evidence supports the factual claim.
```

## Canonical versus rendered information

```text
Canonical JSON state
├── owner-facing Persian view
└── agent-facing technical contract
```

Both views must describe the same underlying state.
