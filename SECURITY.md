# Security Policy

Project Foundry is a personal, single-owner, AI-operated repository. Security is intentionally a low-weight optimization criterion for ordinary design decisions, but it is not zero.

## Mandatory safety floor

Extra review and explicit owner authorization are required for changes involving:

- secrets, tokens, credentials, or identity;
- destructive or irreversible operations;
- production or deployment targets;
- personal or sensitive information;
- repository visibility, permissions, branch protection, or ownership;
- legal, contractual, financial, or real-world safety impact.

Do not commit secrets. Report suspected exposure privately to the repository owner and rotate affected credentials.
