## North Star protection

- Preserve `PF-NORTH-STAR-001` unless the owner explicitly authorizes a versioned change.
- Always report `North Star → Program → Work Package → Task`.
- Never redefine the project around the current task.
- Scope changes must be explicit, versioned, justified, and reflected in canonical state.

## Structural gate before semantic logic

- Parse canonical JSON strictly; reject `NaN`, infinity, malformed JSON, and non-object roots.
- Validate each canonical document against its declared schema before cross-file access.
- Do not coerce malformed values.
- Convert input failures into deterministic `PFV-*` diagnostics without tracebacks.

## Generated critical views

`PROJECT_CHARTER.md`, `SYSTEM_MAP.md`, and `planning/NEXT_WORK.md` are generated by `scripts/render_views.py` from canonical JSON.

- Never edit them manually.
- Update canonical state first.
- Run `python scripts/render_views.py --write --root .`.
- Exact-byte parity is enforced by `scripts/validate_repository.py`.

## Technical authority and Decision Intelligence

AI is the technical decision authority inside approved scope. Consequential implementation choices must compare feasible strategies, hard constraints, criteria, weights, uncertainty, and failure modes. `ai_operability` and `owner_usability` are mandatory criteria for D2/D3 decisions. Preserve deferred `DEC-002`; do not select its strategy without the required research.

## Progress truth

Keep implementation, branch validation, Merge, and current-main verification separate. A model claim is not evidence. Completion requires `current_main_verified` plus evidence.

## Dogfooding

Dogfooding observes and proposes. It may not silently promote an observation into governance, schema, validator, fixture, UX rule, or pipeline stage.

## CI identity and supply chain

- Pull-request validation must check out `${{ github.event.pull_request.head.sha }}` through the combined exact-ref expression in the workflow.
- Push validation must bind to `${{ github.sha }}`.
- CI must print and assert the tested SHA.
- Action dependencies must use verified 40-character commit pins.
- Checkout credentials must not persist.
- Workflow permissions remain read-only.
