# Self-Hosting and Dogfooding Protocol

## Purpose

Use the real construction of Project Foundry as the first reference project and extract reusable, validated pipeline knowledge from actual challenges.

## Observation flow

```text
Observed event
→ fact record
→ challenge or opportunity
→ candidate lesson
→ generalization assessment
→ Decision Intelligence for solution method
→ bounded validation
→ explicit promotion
→ protocol / schema / validator / fixture / UX rule / pipeline stage
```

An observation never becomes a permanent system rule automatically. The initial monitoring model remains manual structured checkpoints plus repository and PR evidence until `DEC-002` is researched and selected.
